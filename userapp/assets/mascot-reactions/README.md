# Mascot reaction assets

Nine individual optimized PNGs copied from the user-provided Printlly_Mascot_Reactions ZIP, extracted at `design/imports/mascot-reactions/Printlly_Mascot_Reactions`.

`MascotReaction.js` selects the corresponding image lazily for the current state. Images preserve transparency and aspect ratio in 96×96 slots. They are static illustrations, including when reduced motion is enabled. The overview sheet is not a runtime asset. Customer avatar eligibility is unchanged; these mascots are not avatar options.

Mappings and original editable Figma component: `reactions.json`, `screen-mapping.json`, https://www.figma.com/design/GLk1d6IiNCnsEFIEIVogwm?node-id=347-547 .
