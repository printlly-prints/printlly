# Printlly shared design tokens

`shared/design-tokens.json` is the shared website/Expo source, generated by
`node shared/generate-design-tokens.cjs` from the exported active Figma variables.
It preserves the original variable names, IDs, Light/Dark values and alias references.
Do not restore the superseded green palette or edit platform colors independently.

`ThemeContext` applies semantic hex and RGB CSS properties; Tailwind maps existing
utility names to these properties. Appearance supports System, Light and Dark, with
browser persistence. Theme changes do not remount forms or reset entered values.

Use `PaperUI` buttons, panels, fields and individual approved artwork, and the shared
`PublicShell`/`DashboardLayout` navigation. `paper.css` binds public layouts and partner
surfaces to the same semantic properties. Body type is self-hosted Inter; headings
are self-hosted Manrope. Prices and pickup digits use tabular numerals.

The latest decoded variables take precedence over older handoff tables. Pale accent
surfaces use the on-accent ink color. Essential field boundaries use the control
border rather than a decorative divider. Controls reserve at least 48px targets;
cards use 20–24px radii and controls 12–16px.

Opening motion uses the active vector plane `265:493`, lasts 300ms and has a static
reduced-motion fallback. Customer discovery never plays event sounds. Authenticated
partner cues require confirmed server order data, respect the local mute setting,
deduplicate API/socket echoes and stop on navigation or interruption.
